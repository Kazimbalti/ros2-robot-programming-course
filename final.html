🎯 Sample Questions

Representative, not exhaustive
  1. Write a .srv for "move LED n to state s" and list every file you must edit to build and use it from my_py_pkg.
  2. Write the Node(...) entry of a launch file that starts robot_news_station as station_x, with robot_name = "X", publishing on /news_x.
  3. An odometry quaternion is (0, 0, 0.707, 0.707). Give the yaw in degrees and explain which way the robot faces.
  4. A LaserScan has angle_min = −2.0 and angle_increment = 0.0111. Which indices cover the front ±20°? Write a function that returns the minimum valid range in that sector.
  5. In a Nav2 run the robot spins in place and never reaches the goal. Give two likely causes and how you would check each.

✅ How to Prepare

  • Rebuild Catch Them All from an empty package; be able to explain every node, topic and service in its graph.
  • Re-run the LIMO labs (Lectures 8–13) in Gazebo, and change one parameter in each to see its effect.
  • Write the go-to-goal controller and the quaternion → yaw formula from memory.
  • Answer every warm-up and exit-ticket question of Lectures 5–14 again, and review each "When things go wrong" table.
