10.1The idea in 10 minutes

flowchart LR S["👀 SENSE
/scan · /imu"] --> T["🧠 THINK
your node:
obstacle ahead? turned enough?"] --> A["🦾 ACT
/cmd_vel"] A -. "robot moves, the world looks different" .-> S
📡

LiDAR = a spinning tape measure. It fires a laser in many directions and measures the distance in each. One sweep is one LaserScan: a list of distances, ranges[], plus the angle of the first one and the step between them.

The LIMO (sim): 360 rays from −2.0 to +2.0 rad (±115°), 0.12–8 m, 8 Hz. A ray that hits nothing gives inf.

🧭

IMU = your inner ear. A gyroscope measures how fast you rotate (rad/s) and an accelerometer measures acceleration. It knows nothing about walls, but it knows exactly how fast you turn, even if the wheels slip.

🃏 Key terms: tap a card to check yourself

LaserScantap to flip
One LiDAR sweep: ranges[] + angle_min + angle_increment.
inftap to flip
"Nothing hit within range_max". Filter it out with math.isfinite().
Sectortap to flip
A slice of angles, e.g. front ±20°. We take its minimum range.
Reactive controltap to flip
Decide only from what you sense now. No map, no goal.
Gyroscopetap to flip
Measures angular velocity (rad/s): imu.angular_velocity.z.
Integrationtap to flip
angle += rate × dt, every message. Small errors add up (drift).

L2Lab 2 — Nearest obstacle

LAB 2 · 20 min

nearest_obstacle.py

1Write the node
📄 limo_lab/limo_lab/nearest_obstacle.py
#!/usr/bin/env python3
import math
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan


class NearestObstacle(Node):
    def __init__(self):
        super().__init__("nearest_obstacle")
        self.create_subscription(LaserScan, "scan", self.callback_scan, 10)

    def callback_scan(self, msg):
        nearest_range = math.inf
        nearest_index = -1
        for i, r in enumerate(msg.ranges):
            if math.isfinite(r) and msg.range_min <= r <= msg.range_max and r < nearest_range:
                nearest_range = r
                nearest_index = i

        if nearest_index == -1:
            self.get_logger().info("Nothing in range")
            return
        angle = msg.angle_min + nearest_index * msg.angle_increment
        side = "LEFT" if angle > 0.1 else "RIGHT" if angle < -0.1 else "AHEAD"
        self.get_logger().info(
            f"nearest: {nearest_range:.2f} m at {math.degrees(angle):.0f} deg ({side})",
            throttle_duration_sec=0.5)


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(NearestObstacle())
    rclpy.shutdown()


if __name__ == "__main__":
    main()

throttle_duration_sec=0.5 prints at most twice per second, so the terminal stays readable.

L3Lab 3 — The obstacle-avoiding wanderer

LAB 3 · 35 min

Drive forward; if something is close in front, turn toward the more open side

1Write wanderer.py
📄 limo_lab/limo_lab/wanderer.py
#!/usr/bin/env python3
import math
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Twist


def sector_min(msg, from_angle, to_angle):
    """Smallest valid range between two angles (radians)."""
    best = math.inf
    for i, r in enumerate(msg.ranges):
        angle = msg.angle_min + i * msg.angle_increment
        if from_angle <= angle <= to_angle and math.isfinite(r) and r >= msg.range_min:
            best = min(best, r)
    return best


class Wanderer(Node):
    def __init__(self):
        super().__init__("wanderer")
        self.declare_parameter("safety_distance", 0.4)   # metres
        self.declare_parameter("speed", 0.15)            # m/s
        self.safety_ = self.get_parameter("safety_distance").value
        self.speed_ = self.get_parameter("speed").value
        self.scan_ = None
        self.cmd_pub_ = self.create_publisher(Twist, "cmd_vel", 10)
        self.create_subscription(LaserScan, "scan", self.callback_scan, 10)
        self.create_timer(0.1, self.control_loop)           # 10 Hz, keeps the watchdog happy

    def callback_scan(self, msg):
        self.scan_ = msg                                     # store...

    def control_loop(self):                                  # ...and decide here
        msg = Twist()
        if self.scan_ is None:
            self.cmd_pub_.publish(msg)
            return
        front = sector_min(self.scan_, -0.35, 0.35)          # about ±20°
        left = sector_min(self.scan_, 0.35, 1.5)
        right = sector_min(self.scan_, -1.5, -0.35)

        if front > self.safety_:
            msg.linear.x = self.speed_                       # path clear: go
        else:
            msg.angular.z = 0.6 if left > right else -0.6    # blocked: turn to the open side
            self.get_logger().info(f"Obstacle {front:.2f} m ahead, turning "
                                   f"{'left' if left > right else 'right'}",
                                   throttle_duration_sec=1.0)
        self.cmd_pub_.publish(msg)


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(Wanderer())
    rclpy.shutdown()


if __name__ == "__main__":
    main()

2Write imu_turn.py: integrate the gyro, stop at the target

Angle turned = sum of (rate × time step). We use the time stamps inside the messages, so it also works with simulation time.

📄 limo_lab/limo_lab/imu_turn.py
#!/usr/bin/env python3
import math
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Imu
from geometry_msgs.msg import Twist


class ImuTurn(Node):
    def __init__(self):
        super().__init__("imu_turn")
        self.declare_parameter("target_deg", 90.0)
        self.declare_parameter("turn_speed", 0.5)                  # rad/s
        self.target_ = math.radians(self.get_parameter("target_deg").value)
        self.speed_ = self.get_parameter("turn_speed").value
        self.turned_ = 0.0                                          # radians so far
        self.last_stamp_ = None
        self.done_ = False
        self.cmd_pub_ = self.create_publisher(Twist, "cmd_vel", 10)
        self.create_subscription(Imu, "imu", self.callback_imu, 50)
        self.create_timer(0.05, self.control_loop)                  # 20 Hz

    def callback_imu(self, msg):
        t = msg.header.stamp.sec + msg.header.stamp.nanosec * 1e-9
        if self.last_stamp_ is not None:
            dt = t - self.last_stamp_
            self.turned_ += msg.angular_velocity.z * dt             # integrate the gyro
        self.last_stamp_ = t

    def control_loop(self):
        if self.done_:
            return
        cmd = Twist()
        remaining = abs(self.target_) - abs(self.turned_)
        if remaining > 0.01:
            # slow down for the last 20 degrees so we don't overshoot
            speed = self.speed_ if remaining > 0.35 else max(0.1, self.speed_ * remaining / 0.35)
            cmd.angular.z = math.copysign(speed, self.target_)
        else:
            self.done_ = True
            self.get_logger().info(f"Done: turned {math.degrees(self.turned_):.1f} deg")
        self.cmd_pub_.publish(cmd)


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(ImuTurn())
    rclpy.shutdown()


if __name__ == "__main__":
    main()

✅ Knowledge checkLecture 10 check: 5 questions

angle_min = −2.0 and angle_increment = 0.0111. Which index looks straight ahead?

(0 − (−2.0)) / 0.0111 ≈ 180.

A range value is inf. What does it mean?

Always filter with math.isfinite() before taking a minimum.

Positive angular_velocity.z on the IMU means the robot turns…

Right-hand rule around z (up): positive = counter-clockwise = left.

Why integrate the gyro instead of using wheel odometry to measure a turn?

Wheels can slip while turning; the gyro feels the body's real rotation. (It does drift slowly over long times.)

The wanderer gets stuck in a corner, turning back and forth. Why?

That is why Lectures 12–13 add mapping and planning.

Is the wanderer open-loop or closed-loop? Is it navigation?

Answer
Closed-loop (it reacts to the LiDAR), but reactive only: no map, no goal, so it's not navigation.

Which sensor would you trust for "how far is the wall?" and which for "how much have I turned?"

Answer
LiDAR for distances; IMU gyro (short term) for rotation.
